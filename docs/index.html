Oracle Dev Tools

A family of small, composable developer tools for Oracle SQL, PL/SQL, data engineering, troubleshooting, documentation and source-level analysis. Built to be useful offline, explicit about limitations, and easy to try.

Design principles

Small tools, explicit limits. The suite prefers a precise “cannot determine this safely offline” over invented certainty. Static analysis is useful, but runtime metadata, synonyms, dynamic SQL, view expansion and optimizer behavior can require a live Oracle database. Each repository documents those boundaries.

Install Oracle Dev Tools locally

This downloads the cross-platform installer. Your browser cannot execute it automatically; you remain in control of the installation.

  • Requires Python 3.10+.
  • Works on Windows, Linux and macOS.
  • Installs the complete CLI suite in ~/.oracle-dev-tools/.
  • Installs the local browser UI and lets you choose one of the supported localhost ports.
  • The local server listens only on 127.0.0.1.

After download, run:

Windows:  py install_all.py
Linux/macOS:  python3 install_all.py

The installer will explain the selected port and the final local URL when it finishes.
