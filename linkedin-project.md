## Description

Oracle Dev Tools is a portfolio suite of small, composable utilities for Oracle SQL, PL/SQL, data engineering, troubleshooting and schema analysis.

The suite currently includes 19 Oracle-focused tools covering SQL impact analysis, execution-plan explanation, data lineage, SQL/PLSQL linting, bind-variable conversion, structural SQL diff, join visualization, ORA error explanation, ETL log analysis, data-quality checks, CSV-to-Oracle loading support, migration checks, SQL complexity metrics, PL/SQL call graphs, dead-code detection and offline schema exploration.

The tools can be used in three ways:

- directly in the browser through the Oracle Dev Tools web playground;
- individually from their GitHub repositories as Python CLI tools;
- as a complete local suite installed with a cross-platform installer for Windows, Linux and macOS.

The local installer creates an isolated Python environment, installs the complete toolkit, includes the browser interface, allows selection of a localhost port, and exposes the tools through both CLI commands and a local web UI.

The project targets Oracle Database 19c, Oracle Database 23ai and Oracle AI Database 26ai, with compatibility differences documented explicitly when applicable.

The suite follows a conservative static-analysis approach: results are presented as deterministic findings or clearly labelled candidates/heuristics, avoiding false certainty where runtime database metadata would be required.
